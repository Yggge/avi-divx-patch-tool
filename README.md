# AVI DivX Tools

Набор утилит для работы с AVI (DivX) в старых играх серии «За стеной» (2002–2003).

---

## Скрипты

### 1️⃣ AVIDXpatchtool.py
- Цель: исправление AVI, чтобы видеоролики запускались в игре.
- Особенности:
  - Исправляет `biPlanes`, `biWidth`, `biHeight`, `FourCC`
  - Проверка уже исправленных файлов
  - Создание резервных копий (.bak)
  - Простой GUI
- Результат: файлы **работают в игре**.

### 2️⃣ AVI hdr Normalizer.py
- Цель: нормализация заголовков AVI без перекодирования.
- Особенности:
  - Стандартизирует `biPlanes`, `biWidth`, `biHeight`, `biSizeImage=0`, `lSampleSize=0`
  - Создаёт резервные копии (.bak)
  - Рекурсивная обработка всех `.avi` в папке
- Результат: игра **не воспроизводит**, но файлы корректны для **конвертации или других проигрывателей**.
