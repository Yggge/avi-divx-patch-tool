# AVI DivX Patch Tool v1.0

Инструмент для исправления некорректных AVI-видео (DivX) в играх серии «За стеной» (2002–2003), включая *За стеной* и *За стеной 2: Иди ты в армию!*.

## Описание

AVI DivX Patch Tool исправляет заголовки AVI, из-за которых видеоролики не запускаются или отображается чёрный экран на современных системах.

## Особенности

- Исправляет ключевые параметры заголовков:
  - `biPlanes`
  - `biWidth` (фиксируется на 384)
  - `FourCC ('divx')`
- Рекурсивный поиск всех `.avi` файлов
- Проверка уже исправленных файлов
- Пропуск файлов, которые не требуют патча
- Создание резервных копий (`.bak`)
- Отображение прогресса и статистики
- Удобный интерфейс

## Совместимость

- За стеной  
- За стеной 2: Иди ты в армию!  

Проверено на оригинальных игровых файлах. Работает чисто и стабильно.

## Примечания

- Не требует прав администратора  
- Безопасен для системы  
- Не изменяет другие файлы, кроме AVI  
- Не рекомендуется запускать из архива или временных папок (Temp)
